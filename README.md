# folk-food-bilingual-guide

AI 赋能民俗美食文化传承与本地文旅外溢传播 Skill —— **精准属地锁定 + 分步引导交互 + 术语库强制译控 + 双语标准化输出**，面向国内游客、本地外语学习者与外籍到访游客的轻量化民俗美食双语科普 Skill。

## 使用方法（开门见山吧）

### 给普通用户：豆包移动端即开即用

不需要部署。直接把仓库里的 `SKILL.md` 单文件通过手机分享给豆包（**务必开启专家模式**），然后发一句 **"开始运行这个 skill"** 即可唤醒；之后跟着对话一步步选城市、选区县、选品类、选维度就行。

唤起语言决定交互语言（中文唤起 → 中文模式；英文唤起 → 英文模式），随时可以手动指定"中英双语对照"。

### 给开发者：安装到宿主 Skill 目录

把整个 `folk-food-bilingual-guide/` 目录放进宿主的 skills 路径即可：

- 项目级：`<项目根>/.trae/skills/folk-food-bilingual-guide/`
- 用户级：`~/.claude/skills/folk-food-bilingual-guide/`

目录名必须与 `SKILL.md` 中的 frontmatter `name` 保持一致，否则部分宿主会拒绝加载。

## 它解决什么问题

民俗美食是地方民俗文化中最具烟火气、最易被游客感知的载体，但现有工具存在四个结构性缺陷：

| 痛点 | 表现 |
|------|------|
| **内容同质化** | 大众旅游平台以流量逻辑推送网红美食与通用商圈，正宗民俗特色被算法边缘化 |
| **获取不精准** | 传统海报/推文/短视频单向传播，游客无法按需精准获取属地小众民俗内容 |
| **翻译不可控** | 民俗专有名词、传统工序、文化寓意的翻译缺乏统一规范——人工成本高标准不一，通用 AI 直译失真、文化内涵损耗 |
| **传播局限本地** | 缺乏标准化双语传播体系，地方民俗文化难以突破地域限制、实现文化外溢 |

本 Skill 以"民俗垂直内容筛选 + 术语强制译控 + 双向双语服务"三重机制直击上述痛点。

## 核心功能

| # | 功能 | 说明 |
|---|------|------|
| 1 | **智能唤起适配** | 中文唤起→全程中文交互；英文唤起→全程英文交互；可手动指定中英双语输出 |
| 2 | **分层定位筛选** | 城市→区县两级层级定位，不读取设备 GPS，用户主动确认；支持简称/错别字模糊识别，区县缺失时降级查询全市 |
| 3 | **民俗品类精准筛选** | 仅推荐本土非遗/百年传承/节庆礼俗必备的民俗美食，自动剔除网红餐饮、商圈流水线小吃 |
| 4 | **定制化内容科普** | 起源发展 / 制作工艺 / 民俗寓意三个维度，用户自主选择 |
| 5 | **多媒体智能适配** | 自动匹配高清民俗美食实景图与工艺展示图，执行五项图片筛选原则（民俗真实性/内容相关性/属地匹配/版权合规/清晰度），图文结合 |
| 6 | **翻译专属管控** | 建立民俗特色术语专属词库，强制匹配标准译文，结合文化保真/一致性/可读性等翻译原则，规避直译失真 |

## 交互流程（分步引导）

```
用户唤起 Skill
│
├─ Step 1. 确认所在城市（支持简称、错别字模糊识别）
│
├─ Step 2. 确认所在区县（可选；不清楚则降级全市查询）
│
├─ Step 3. 联网检索 → 列出该属地【民俗主食 / 民俗小吃】候选清单（每类 3-5 项）
│
├─ Step 4. 用户选定条目后，选择内容维度（起源 / 工艺 / 寓意）
│
└─ 输出：权威科普文本 + 标准化专有名词 + 民俗图片（或检索指引卡）+ 文旅实用指引
      │
      └─ 结尾追问：纯中文 / 纯英文 / 中英双语？是否继续查询其他属地？
```

**防跳步规则**：每一步必须单独提问并等待用户回复，即使用户一次性提供了多步答案，流程仍须逐步骤走完。


## 设计边界（请如实引用）

- **数据依赖**：民俗内容库与术语库当前以胶东片区（烟台/威海）为首个样本区域，其他属地数据需后续调研补充；Skill 架构支持按属地标签逐条扩展
- **事实性断言**：民俗起源、非遗认定级别等事实性断言依赖联网检索权威来源（文旅局官网/非遗档案/地方志），Skill 本身不内置事实库
- **图片获取**：图片输出依赖平台搜图卡片能力，无法直接展示时自动降级为"三段式检索词 + 建议渠道"指引卡
- **适用边界**：仅面向"民俗/非遗地方特色"垂直内容；不做通用旅游推荐、网红美食评价、非民俗类内容科普
- **不读取 GPS**：地理位置由用户主动输入确认，降低权限依赖、提升通用性
